Overview

这是什么？

AI 大头贴 = 传统机器大头贴 × AI 实时风格化 + AI 短视频生成。 路人站到摄像头前，屏幕里实时出现「动漫版的你」（跳舞、做鬼脸都同步）；按下按钮录制 3~5 秒动作， 约 1 分钟后得到一支带 BGM 的动漫风短视频，扫码即可带走发朋友圈。

美颜滤镜静态 AI 大头贴我们的动态版
原理原照片调色扩散模型重绘单张实时风格化视频流 + 逐帧重绘短视频
产出还是原照片一张图一支 MP4 短视频
现场效果无感看一眼大屏上「动画版的你」跟你同步跳舞
WHY 01

现场传播力最强

视频比图片更易刷屏，宣发与「最佳人气奖」双收。

WHY 02

围观即展位

实时动漫化大屏本身就是吸睛装置，路过必停。

WHY 03

技术完整度高

实时 CV 推理 + 生成模型优化（TensorRT）+ 视频工程 + Web 服务。

WHY 04

演示零门槛

不用解释，站上去 10 秒就被效果说服。

Modes

三种模式 · 一套底座，三个皮肤

同一套采集 / 推理 / 合成底座，根据场景切换三种「皮肤」。

🎥
MODE A · 保底

实时风格化直播

摄像头画面逐帧实时变成动漫 / 赛博风格——你跳舞，屏幕里的「动画版你」同步跳。无人时大屏常驻此模式，本身就是吸睛装置。

AnimeGANv2 逐帧10~20ms/帧 · 30fps+必做
⭐
MODE B · 核心体验

录制动作 → 风格化短视频

按下按钮录 3~5 秒动作，约 1 分钟后得到带 BGM 的动漫风 MP4，局域网二维码带走。

逐帧批处理RIFE / EbSynth 平滑ffmpeg + BGM + Logo
🎆
MODE C · 彩蛋

真·生成式视频

用 AnimateDiff + ControlNet-OpenPose 生成「动画角色跟你做同样动作」的片段。单片段 2~5 分钟，不适合现场排队。

AnimateDiffControlNet-OpenPose离线预生成
模式 B 全链路： 录制 3~5s（24fps，约 90 帧）→ 逐帧风格化 → 时序平滑（关键帧 + EbSynth 传播 / RIFE 补帧，消除闪烁）→ ffmpeg 合成 + BGM + 片尾 Logo → 输出 MP4 → 局域网二维码下载。

软件栈

PyTorch ≥2.7 + cu128

RTX 5070（Blackwell/sm_120）必需，否则 "no kernel image"。

AnimeGANv2

模式 A 保底引擎，轻量 GAN 逐帧。

StreamDiffusion

实时扩散管线，TensorRT + 帧队列。

OpenCV + FFmpeg + RIFE

模式 B：合成、加 BGM、补帧去闪烁。

rembg / mediapipe

一行代码抠人，人像分割。

diffusers

SD-Turbo / SDXL-Turbo 官方库。

FastAPI

局域网二维码取图 / 取视频。

photobooth-app

开源照相亭交互与分享参考。

Codebase

仓库结构

# 纯函数式核心管线，互相解耦，可两人并行开发
app/
├── main.py                入口（模式分发）
├── config.py              全局配置：摄像头/风格预设/路径
├── core/
│   ├── camera.py            摄像头采集线程（始终取最新帧）
│   ├── stylizer_anime.py    AnimeGANv2 实时风格化（模式 A）
│   ├── stylizer_sd.py       SD 生成精修照（扩展）
│   ├── stylizer_mock.py     OpenCV 描边 mock 引擎（纯流程验证）
│   ├── video_batch.py       视频帧批处理（模式 B）
│   └── compose.py           ffmpeg 合成 MP4 + BGM
├── ui/
│   └── realtime_window.py   全屏窗口 + HUD（FPS/按键提示）
└── server/
    ├── api.py               FastAPI 取图服务
    └── qr.py                二维码生成
scripts/  tests/  docs/        自检脚本 / 回归测试 / 文档
分工接口契约： 推理侧只需交付 stylizer(frame) → frame 与 stylize_frames(frame_paths, stylizer, out_dir, progress)；应用侧只依赖这两个接口 + compose.frames_to_video()。双方通过函数签名解耦，可完全并行。

Risk

风险与预案

风险概率预案
长时间高负载降频、帧率衰减高散热支架 + 性能模式 + 任务间隔冷却；实时模式降分辨率
视频合成失败 / 闪烁严重中降级输出「关键帧九宫格图」；RIFE 参数预调
现场灯光差中自备补光灯；曝光自动校正
StreamDiffusion 调不通中AnimeGANv2 实时版兜底，核心体验不受影响
现场断网低全流程纯局域网，模型权重提前下载本地
排队拥堵低二维码异步取结果，大屏轮播维持围观
