Why this theme?

奶蛙的流行
本质上不是审美选择，而是情绪选择

现在的互联网太卷了，连可爱都要卷成模板，可我们想做一台允许人暂时不精致的照相亭：一只丑萌、癫狂、甚至有点“精神污染”的奶蛙，显得格外真实和“解腻”。

01 / 反骨

可爱，不必经过审核

滤镜负责完美，奶蛙负责把完美轻轻推倒。丑萌一点、荒诞一点，反而更像真的我们。

02 / 解压

表面冷静，内心已经蛙叫

有些情绪不需要大道理，只需要一个可以大笑三秒的出口。它不解决压力，但允许我们喘口气。

03 / 共鸣

一个人发疯，大家接梗

拍一张、录一段、发给朋友。荒诞的画面有了共同语言，快乐就从屏幕这边传到那边。

所以我们做 Naiwa - PhotoBooth：把“看奶蛙的梗”变成“走进奶蛙的世界”——希望最终能留下一张照片或一段视频，带走一小会儿不必正常的快乐。

Overview

这是什么？

把 VTube Studio 的 Live2D 角色带进一台可互动的大头贴展台。 手机面捕驱动奶蛙的表情与动作；展台负责选择角色、触发动作，以及拍照、录像和局域网扫码取件。

现场的一步观众做什么展台做什么
相遇站到镜头前，选一只奶蛙展示角色状态与实时预览
互动做表情、点动作按钮面捕驱动 Live2D，热键触发角色动作
留念拍照或录一段短视频保存结果，生成局域网取件二维码
进度说明：以下是计划中的观众体验。手机面捕驱动角色、普通摄像头拍照与扫码取件已分别可用；VTubeStudioCam 画面尚未稳定接入展台拍摄输入，Live2D 成片与扫码交付仍待端到端验收。

拍摄交付

OpenCV × FastAPI × QR

展台预览、拍摄与局域网扫码取件；现有照片链路可用，VTubeStudioCam 帧读取尚未打通。

本地路线只作备选：早期 PyTorch / AnimeGANv2 风格化效果未达预期，不作为展示主线；VTS 角色画面进入拍摄与交付，是当前最关键的待完成接口。

Risk

风险与预案

风险当前影响应对
VTubeStudioCam 读取不到有效帧角色画面无法进入成片核对 VTS 虚拟摄像头、设备索引与采集后端；验收前不宣称已打通
手机面捕或 API 连接中断角色不跟随或无法触发动作提供连接状态与重试入口；现场先验证手机与桌面端连接
灯光、背景影响拍摄表情跟踪与构图不稳定准备补光和预设背景，在实际展位上做拍摄测试
角色素材授权范围不明展示和传播受限核对 Live2D 模型与背景素材许可；仅使用获授权的演示素材
扫码取件连接失败观众无法带走作品提前核对局域网、手机访问与文件服务；保留现场查看结果的路径
展示原则：已完成的角色互动和普通照片取件可以现场演示；VTS 角色同框成片只有在完整链路实机通过后才作为已实现功能展示。
Final words

结语：地球还要被这样的萌物统治多久？

奶蛙的流行，反映的是我们内心对简单快乐的渴望，以及对严肃叙事的疲惫。它可能很快会被下一个梗取代，但它的出现证明了一点：在高度原子化的社会里，我们依然渴望通过某种荒诞的方式，找到彼此的共鸣。

最后，温馨提示：请不要在深夜戴着耳机刷奶蛙视频，否则你的笑声可能会和它一样“领先版本20年”。
