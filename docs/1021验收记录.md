## 修复的问题

1. 实时启动时等待首帧，避免对空图像预热；退出时释放摄像头。
2. 窗口仅处理新采集的帧，避免把重复画面计入 FPS。
3. mock 视频管线不再强制导入 torch；真实模型分支仍使用推理模式。
4. 输入视频无法打开或没有有效帧时明确报错。
5. 输入帧、风格化帧分别保存，合成时保留源帧率精度。
6. 修正 FFmpeg 背景音乐参数顺序；短音乐循环播放，避免截断视频。
7. 图片读写兼容 Windows 中文路径，失败时明确报错。
