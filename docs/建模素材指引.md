# 建模素材指引（本地已下载 + 手动获取渠道）

> 更新：2026-10-21。所有本地素材仅限比赛展示用途，使用前阅读各模型授权。

## 一、本地已就位（开箱即用）

### Live2D 官方模板 ×8 —— `refs/live2d-samples/Samples/Resources/`
Haru / Hiyori / Mao / Mark / Natori / Ren / Rice / Wanko
- 每个 .model3.json 可直接被 Open-LLM-VTuber / VTube Studio 加载
- 授权：逐一核查 Live2D 免费素材许可、角色单独条款与是否准许再分发；可在本机展示不代表可以上传模型文件
- 预览：用 Cubism Viewer 打开 .model3.json，或直接跑 Open-LLM-VTuber

### VRM 3D 模型 —— `refs/vrm-samples/`
Seed-san、VRoid 男女款、Sakurada_Fumiriya、发型示例、Orion、meebits 等
- VRM 是 3D 格式，适用于 VSeeFace / Warudo 等支持 VRM 的软件；VTube Studio 的 Live2D 导入流程不直接支持 VRM
- 来源：madjin/vrm-samples（社区样本合集），商用前逐个确认子授权

### 数字人软件（方案乙驱动端）
- VTube Studio（Steam 免费）/ VSeeFace（免费）/ Warudo（免费版）；VTube Studio 使用 Live2D Cubism 模型，VRM 要使用相应的 3D 驱动软件
- Open-LLM-VTuber：`refs/Open-LLM-VTuber`（含 LLM 对话+面捕，中文文档）

## 二、需要手动下载（要登录/勾选，按需获取）

| 素材 | 渠道 | 步骤要点 |
|---|---|---|
| 更多 Live2D 模型 | nizima.com / booth.pm 搜「Live2D 無料」 | 选"展示可/非商业可"条款，下载 zip 解压出 .model3.json |
| Live2D 官方 PSD 源文件 | live2d.com → Learn → Sample Data | 填邮箱表单后给下载链接（含分层工程，学蒙皮用） |
| VRM 角色 | hub.vroid.com | 登录 → 筛选「允许使用」→ 下载 VRM |
| 自捏 3D 角色 | VRoid Studio（vroid.com/studio） | 免费，捏完导出 VRM |
| **自拍生成 3D 头像** | readyplayer.me | 上传自拍自动生成（可做成展台互动玩法） |
| 动作数据（跳舞等） | mixamo.com（Adobe 账号） | 选动作 → 下载 FBX → 重定向到 VRM |
| MMD 动作 | bowlroll.net / ニコニ・コムンズ | 逐个看条款，配 VRM 是社区常规组合 |
| PNGTuber 素材 | booth.pm 搜「PNGTuber」 | 张嘴/闭嘴两帧图 + 麦克风驱动，零成本兜底 |

## 三、⚠️ 版权红线

1. **禁止使用从游戏中提取的 rip 模型**（原神/MHY 模型站等）——侵权且违反比赛"素材来源合法"条款
2. 每个下载的模型**截图保存其利用条款页**，验收/答辩备查
3. 第三方模型包一律放在已忽略的 `refs/`，**不要 push 到公开仓库**；`assets/` 未被整体忽略，放入其中的文件可能被提交。经明确许可公开再分发的原创/授权素材须逐项复核后才可入库
4. AI 生成的角色立绘（Nano Banana / 即梦 / 本地 SD）用于展示 OK，AI 使用声明如实填写

## 四、推荐组合（10 分钟搭完方案乙展台）

```
1. Steam 装 VTube Studio
2. 从 refs/live2d-samples 挑一个模型导入（如 Haru）
   或从 refs/vrm-samples 挑 VRM 用 VSeeFace 驱动
3. OBS 抓 VTube Studio/VSeeFace 窗口 → 输出大屏
4. 微笑/挥手测试延迟
```
