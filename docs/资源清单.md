# 开源资源清单（按项目流程整理）

> 更新：2026-10-21。⭐ = 本项目重点依赖。

## 一、建模阶段（角色/形象制作）

| 资源 | 类型 | 说明 |
|---|---|---|
| VRoid Studio（免费） | 3D 捏脸 | 零美术基础捏 VRM 角色 |
| VRoid Hub / Booth.pm / nizima | 模型市集 | 合法授权 Live2D/VRM 现成模型（逐个看条款） |
| Live2D Cubism | 2D 蒙皮 | 原画变皮套人的标准工艺 |
| VTube Studio（Steam 免费） | 驱动引擎 | 摄像头面捕 + 渲染，方案乙零代码核心 |

## 二、训练阶段（自定义风格，低优先级）

| 资源 | 类型 | 说明 |
|---|---|---|
| kohya-ss/sd-scripts | LoRA 训练底座 | 事实标准 |
| Akegarasu/lora-scripts（国内·秋叶） | 一键训练整合包 | 中文界面，新手友好 |
| ComfyUI Realtime LoRA Trainer | ComfyUI 内训练 | 参考图直接训风格 LoRA |
| CivitAI / LiblibAI（国内） | 模型市集 | 现成风格 LoRA 下载 |
| IP-Adapter / InstantStyle | 零训练风格迁移 | 1 张参考图贴画风（首选，免训练） |

## 三、功能应用阶段（核心管线）

### 实时风格化（模式 A）
| 资源 | 说明 |
|---|---|
| ⭐ bryandlee/animegan2-pytorch | 轻量 GAN 保底引擎，单帧 10~20ms |
| ⭐ cumulo-autumn/StreamDiffusion | 实时扩散管线（RTX4090 图生图 91fps），TensorRT+帧队列 |
| 🆕 chenfengxu714/StreamDiffusionV2 | 2026 新版：视频扩散架构（Wan2.1-1.3B）、多 GPU、无需 TensorRT，时间一致性更好 |

### 视频工程（模式 B）
| 资源 | 说明 |
|---|---|
| hzwer/Practical-RIFE | 补帧去闪烁 |
| FFmpeg | 合成标配（winget install ffmpeg） |

### 数字人（方案乙备选）
| 资源 | 说明 |
|---|---|
| ⭐ Open-LLM-VTuber/Open-LLM-VTuber（国内团队） | 开源数字人全套：LLM 对话+ASR+TTS+Live2D 面捕，本地运行，中文文档 |
| KwaiVGI/LivePortrait（快手） | 表情移植：角色图+驱动视频 → 原画动起来 |

### 整机交互参考
| 资源 | 说明 |
|---|---|
| photobooth-app（photobooth-app.dev） | 开源照相亭整站：拍照/滤镜/二维码取图交互 |

## 四、依赖顺序图

```
保底主线（第1周）
  animegan2-pytorch → 摄像头实时 / rembg+mediapipe → 抠图 / ffmpeg → 合成
核心冲刺（第2周）
  StreamDiffusionV2（或V1） → 实时扩散画质 / Practical-RIFE → 时序平滑
方案乙副线（一晚试错）
  VRoid+VTube Studio 零代码 → 不满意再上 Open-LLM-VTuber 自研
可选深水区
  lora-scripts / IP-Adapter → 自定义画风 / LivePortrait → 原画表情驱动
```
